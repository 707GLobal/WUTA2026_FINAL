# 标定数据审计（2026-10-11）

审计范围：当前项目源码、配置、全栈启动脚本，以及脚本引用的本机 ZED 驱动、SDK 标定文件和 `/home/wuta/BiaoDing/data`。本次没有启动硬件、改变标定值或验证实时话题。下文“未找到”指上述范围内没有可复查的记录，不等同于设备内部从未完成标定。

## 结论

M1—ZED—车辆的静态几何链已经有数据，数值自洽；相机内参和双目出厂参数也存在。完整实车定位、建图和控制仍缺少若干标定的确认与验证记录，其中最优先的是华测安装参数/输出参考点、传感器时间同步和转向实际响应。不能仅凭 TF 链闭合判定物理安装准确。

## 几何数值复核

相机雷达外参约定为 `p_camera = R * p_lidar + t`，帧名为 `zed_left_camera_optical_frame` 与 `rslidar`，单位为米。

```text
R = [ 0.0106084145794527  -0.9996151424057500  -0.0256325693843221
      0.0191546763256897   0.0258324536958275  -0.9994827575855980
      0.9997602512177450   0.0101119438875302   0.0194213458814503 ]
t = [0.0424115576688025, 1.0792997325922, 1.64729536709387]

base_link → zed_camera_link:
translation = [0.672897441073, -0.061631385726, 1.031499915026]
quaternion xyzw = [0.012868092578, -0.009645382346,
                   0.005180829135, 0.999857258714]
```

检查结果：两个 camera_lidar YAML 内容相同；det(R)=1.0；旋转正交误差最大约 4.44e-16；车辆相机四元数模长约 1.0000000000003986。

本机 ZED 2i URDF 确认 `zed_camera_link → zed_left_camera_optical_frame` 为 xyz `[-0.01, 0.06, 0.015]`，rpy `[-pi/2, 0, -pi/2]`。连乘后 `base_link → rslidar` 的平移为 `[2.33, 0, 0]`，姿态约 `[0,0,0]`，误差只有浮点舍入量级。该闭合来自推算过程，不能替代独立测量。

## 采集数据中值得复核的差异

1. 0001—0031 的校正内参一致：1280×720，fx=fy=523.9627685546875，cx=633.54833984375，cy=348.58245849609375，D 全零。
2. 0032 的 fx=fy=522.8238525390625，cx=633.5645141601562，cy=348.58599853515625。焦距变化约 0.22%。应确认 MATLAB 最终使用了哪些帧、采用哪组内参，以及第 32 帧是否来自重新打开相机或自标定变化；目前不能判定它造成了实际外参误差。
3. 主索引中相机与雷达 header.stamp 不属于同一时间基准，采集工具按主机接收时间配对。32 帧接收时间差绝对值的中位数 33.29 ms、P95 71.022 ms、最大 74.61 ms。这是历史采集数据，不能当作当前运行时同步误差。
4. 现运行配置 `rsm1_hardware.yaml` 已使用 `use_lidar_clock: false`，华测使用 GPS 换算时间；仍需验证主机与 GPS 时钟对齐及采集到时间戳的延迟。

## 资料管理问题

- 根目录与感知目录各有一份运行外参，目前一致，但未来可能漂移。以全栈默认读取的 `config/camera_lidar.yaml` 为当前运行入口，并明确同步方式。
- 两份运行外参都被 Git 忽略，新克隆不会自动获得。需要独立的车辆标定包/部署清单，包含设备序列号、日期、安装版本、校验和及误差报告。
- 感知标定 README 仍写旧目录 `/home/wuta/lyx/WUTA/...`；原始采集与 SDK 参数也位于项目之外。需要在部署资料中登记这些外部依赖。
- 当前没有固定 ENU 原点，配置自动使用首个有效定位。这是运行坐标原点策略；如需复用历史地图，再记录/固定统一原点，不应将其误认为缺少传感器标定。

建议顺序：先导出并核对华测设备安装参数，再验证时间同步与转向响应；随后补齐外参误差报告及独立车辆尺寸验证，最后按需求进行深度位置融合和滤波/控制参数实测。
